参与贡献

教师的真实小问题最值得被认真解决。欢迎提需求、报错、改文案、补测试或贡献新工具。

提议新工具

请说明使用者、核心问题、典型输入与输出，以及能否完全在浏览器本地运行。不要在 Issue 中粘贴真实名单、成绩或作业。

报告问题

请提供页面、复现步骤、预期与实际结果，以及浏览器和设备信息。截图和示例数据必须脱敏。

贡献代码

  1. 先阅读仓库中的 贡献指南 与 工具规范。
  2. 复制 tools/_template/，保持一工具一目录。
  3. 运行 npm run check，并完成键盘、窄屏和跨浏览器走查。
  4. 在 PR 中说明隐私影响、测试结果及 AI 辅助范围。
安全或隐私报告不得包含真实数据或可直接利用的敏感细节；在仓库配置私密安全渠道前，请只提交不含利用细节的公开提醒。
