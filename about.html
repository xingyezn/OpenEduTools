关于 OpenEduTools

这是一个免费、开源、无需登录的教师微工具集合。每个工具只解决一个清晰问题，并优先在浏览器本地完成处理。

我们坚持什么

  • 浏览器优先：打开静态网页即可使用。
  • 本地优先：名单、成绩、文本和文件默认不离开设备。
  • 无后台、无账号：不建立教师或学生画像。
  • 开放协作：代码、规范和发布过程公开。

隐私说明

V0.1 不包含广告、第三方追踪器、远程字体或联网 AI。名单、成绩、文本和文件只在浏览器内处理，刷新后即清除。主题、收藏和最近使用会以 openEduTools: 前缀保存在浏览器本地；最近使用只记录工具 ID 和访问时间。

为了解哪些工具真正有用，网站会记录匿名的工具打开、使用、收藏和分享次数，只包含工具 ID 与事件类型，按天聚合，不含任何用户输入、文件、账号或浏览器指纹。统计服务不可用时工具照常运行，离线包完全不发送数据。详见 隐私说明文档。

你可以在浏览器站点设置中随时清除这些偏好。即使本地存储不可用，工具核心功能仍可使用。

技术边界

网站使用 HTML5、CSS3 和原生 JavaScript，可作为纯静态内容部署到 GitHub Pages。没有服务端数据库、账号同步、PWA、插件系统或必须执行的构建步骤。
