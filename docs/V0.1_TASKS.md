# OpenEduTools V0.1 开发任务清单

版本目标：交付一个可部署到 GitHub Pages、具有统一体验和 5 个本地工具的最小可用开源网站。

## 0. 范围

### V0.1 包含

- 静态站点骨架与 GitHub Pages 部署；
- 工具元数据、索引生成和校验；
- 首页搜索、分类、收藏、最近使用；
- 统一 UI、响应式、明暗主题与基础无障碍；
- 项目介绍、隐私说明和贡献入口；
- 匿名使用统计与首页热门排行；
- 5 个首批工具；
- 最小测试与 CI。

### V0.1 不包含

- 账号、登录、同步、数据库或自建 API；
- 广告、第三方追踪、用户画像或付费能力（第一方匿名事件计数除外）；
- React、Vue、Astro 等框架或必须运行的打包链；
- 需要联网发送用户输入的 AI 功能；
- 多语言、PWA、服务工作线程和完整离线站点缓存；
- 插件系统、在线工具编辑器或社区积分体系。

## 1. 里程碑与依赖

```text
M0 仓库基线
  └─ M1 设计系统与页面壳
      ├─ M2 元数据与工具目录
      │   └─ M3 搜索 / 分类 / 收藏 / 最近使用
      └─ M4 工具公共模板
          └─ M5 首批 5 个工具
M2 + M3 + M5
  └─ M6 测试、文档与发布
```

建议按顺序完成 M0–M4，再并行开发 M5 的工具，最后进入 M6。

## 2. 优先级

- **P0**：V0.1 发布阻断项。
- **P1**：V0.1 应完成；如延期必须记录原因。
- **P2**：优化项，可移至 V0.2。

### OET-023 实现目录加载与错误状态 — P0

## M5：首批工具

### OET-050 随机点名 — P0

功能：粘贴每行一个姓名的名单，随机抽取一人。

- [ ] 忽略空行，提供是否去重选项与有效人数。
- [ ] 使用 `crypto.getRandomValues()` 生成随机索引，并提供兼容回退。
- [ ] 可选择“抽中后暂时移出”，支持重置候选池。
- [ ] 显示抽取结果与剩余人数。
- [ ] 不默认保存名单，不暗示具有正式抽签效力。

验收：空名单、单人、重复姓名、多次抽取和重置行为正确；名单不离开浏览器。

### OET-051 随机分组 — P0

功能：将每行一个姓名的名单按组数或每组人数随机分组。

- [ ] 支持“指定组数”和“指定每组人数”两种模式。
- [ ] 忽略空行，可选去重。
- [ ] 使用可靠洗牌算法，避免 `sort(() => Math.random() - 0.5)`。
- [ ] 尽可能均衡分组并解释余数分配。
- [ ] 支持复制全部结果和重新分组。

验收：1 人、组数大于人数、不能整除、重复姓名和大名单均有明确结果或提示。

### OET-052 课堂计时器 — P0

功能：为课堂活动提供倒计时和正计时。

- [ ] 支持小时/分钟/秒设置、开始、暂停、继续、重置。
- [ ] 支持正计时模式和常用时长快捷项。
- [ ] 使用时间戳计算，避免标签页休眠造成累计漂移。
- [ ] 时间结束时提供可见提示；声音默认关闭或需用户主动允许。
- [ ] 支持全屏或大字展示；减少动画设置下无闪烁效果。

验收：暂停/继续、切换标签页、到时、重复开始和零时长均正确。

### OET-053 文本清洗 — P0

功能：对粘贴文本执行可预览、可组合的基础清理。

- [ ] 去除首尾空格、合并连续空格、合并多余空行。
- [ ] 删除空行、行去重（保留首次出现顺序）。
- [ ] 可选统一中英文标点或换行，但默认不做有损转换。
- [ ] 实时显示字符数、行数和处理前后差异摘要。
- [ ] 支持复制结果、下载 `.txt` 和撤销到原文。

验收：中英文、空文本、不同换行符、重复行和超长文本不丢失未选择的信息。

### OET-054 成绩统计 — P0

功能：根据本地输入的一列分数计算描述性统计和分布。

- [ ] 支持粘贴分数或上传简单 CSV；提供明确格式示例。
- [ ] 验证非数字、缺失值和用户设置的分数范围。
- [ ] 计算有效人数、平均数、中位数、最高、最低、及格率。
- [ ] 支持自定义及格线和分数段，显示各段人数与占比。
- [ ] 明确舍入规则，不显示学生姓名，不默认持久保存。
- [ ] 支持导出汇总，不导出未选择的原始数据。

验收：空数据、小数、边界分数、非法值、单个分数和常见 CSV 引号规则均正确；用独立样例核对统计值。
