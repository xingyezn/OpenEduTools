Markdown 转 Word

在浏览器本地把 Markdown 转换为可编辑的 Word（.docx）文档：标题、列表、表格、引用、代码块都会保留，行内与独立公式会转换为 Word 原生的公式对象。右侧实时预览默认示例，你可以直接修改源文后重新导出；文档只在本地生成，不会上传。

Markdown 仅在本页内存中处理

预览

支持的语法：标题、有序/无序列表、表格、引用、代码块、粗体/斜体/删除线、链接，以及行内公式 $...$ 与独立公式 $$...$$。公式支持分数、根号、上下标、求和/积分、括号、矩阵等常见写法。
