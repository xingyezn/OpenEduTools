PDF TOOLKIT

PDF 工具箱

所见即所得地处理 PDF：合并时可拖动缩略图调整页面顺序、删除不要的页面；编辑时可点击页面放置文字或图片，并拖动调整位置。所有文件只在本机处理，不会上传；内置文字字体仅支持英文、数字和常用符号。

PDF 仅在本页内存中处理

选择或拖入 PDF 文件

支持一次选择多个文件；合并、提取、编辑都在本地完成。

—100%

选择文件后在此预览

合并

拖动缩略图调整顺序，点 × 删除该页。

提取页面

已选 0 页

点击左侧缩略图选择要提取的页面。

添加内容

尚未载入

选工具后点击页面放置，可拖动位置、拖动右下角缩放、双击改字、点 × 删除。

解析并编辑原文

双击文字即可修改；清空内容并确认即删除该文字。导出时会用底色覆盖原文字并重绘（支持中文，使用所选系统字体）。

说明：本工具内置本地版 pdf-lib 与 pdf.js（均为 MIT）完成读写与预览，全程离线。已加密或损坏的 PDF 可能无法处理；「文字」为在页面上新增文字，无法修改已有文字。
