PDF 工具箱

在浏览器本地处理 PDF：合并多个文件、按页码拆分或提取页面、旋转与删除页面，并在页面上添加文字或图片，最后导出新的 PDF。所有文件只在本机处理，不会上传；文字使用内置字体，仅支持英文、数字和常用符号，中文需在源文件中已存在（无法原地修改已有文字）。

PDF 仅在本页内存中处理

合并 PDF

选择多个 PDF，用「上移 / 下移」调整顺序后合并为一个文件。

拆分 / 提取

载入一个 PDF，提取指定页面为新文件，或把每一页拆成单独文件打包下载。
